查看功能明细 ↘ 在线排版

YI TUO HUB / GZH CLI

排版与存稿，一条命令完成。

它不是一个后台，也不是另一个编辑器。Agent 写好 Markdown 以后，调用本地 CLI，选择排版风格，必要时直接把结果交给微信公众号草稿箱。

01 / LAYOUT

排版 CLI

把 Markdown 转成公众号正文 HTML。支持本地图片、远程图片和 YI TUO HUB STUDIO 的基础主题与高级主题。

yituo-hub-gzh layout article.md
--style violet-studio --level L4 打开在线排版 ↗
02 / DRAFT

推稿 CLI

在用户明确要求时，上传图片、创建草稿并回读核对。只存草稿，不调用发布接口，发布权始终留在公众号后台。

yituo-hub-gzh draft article.md
--style violet-studio --cover cover.jpg 查看配置清单 ↘

THE FLOW / 03 STEPS

从文件到草稿，三步完成。

CLI 请求直接发往微信接口，不经过 YI TUO HUB 的中心服务器。图片只在当前进程和临时目录中处理。

01

交给 Agent

准备好 Markdown 和图片，路径以文章文件所在目录为基准。

02

选择风格

运行 styles --json，让用户决定主题和高级等级。

03

核对草稿

微信返回成功后，再回读标题、封面和草稿状态。

BEFORE DRAFT / CONFIG CHECK

先把配置，准备好。

第一次推稿前，Agent 会引导用户准备自己的公众号 AppID、AppSecret 和实际运行环境出口 IP。密钥只放在调用 CLI 的本机，不放进网页或 Markdown。

打开微信公众号开发者后台 ↗
  1. 01
    AppID / AppSecret配置在本机环境变量或 0600 配置文件
  2. 02
    服务器白名单把实际出口 IP 加入目标公众号白名单
  3. 03
    封面与排版风格没有正文图片时，用 --cover 指定封面

QUICK START / LOCAL CLI

装好 CLI，直接调用。

需要 Node.js 20 或更高版本。发布包同时包含 CLI 和 Agent Skill。

curl -fsSL https://cli.yituohub.com/install.sh | bash

每个写公众号的人都被排版折磨过：调字号、对颜色、截图做卡片……写文章 40 分钟，排版两小时。现在，这件事可以还给机器了。

01

YI TUO HUB GZH CLI 是什么

ORBITAL WAVE

一个跑在你自己电脑上的命令行工具：把 Markdown 一键排成公众号高级排版，并经微信官方接口直接送进草稿箱。

UNORDERED / 要点列表

—33 套编辑部级主题：科技、情感、测评、财经全覆盖
—6 级高级排版：同一篇文章，6 种呈现
—图片全自动：本地图、远程图自动转微信素材
—Agent 原生：输出标准 JSON，AI 说一句话就能出稿
02

三步上手

ORBITAL WAVE

安装（需要 Node.js 20+）：

BASH

curl -fsSL https://cli.yituohub.com/install.sh | bash

然后像平常一样写 Markdown，一条命令：

BASH

yituo-hub-gzh draft article.md --style violet-studio --level L6

排版完成 → 图片上传 → 草稿入箱 → 自动回读核对。打开后台，文章已经躺在草稿箱里。

03

写在最后

ORBITAL WAVE

安全上它很较真：密钥只存本机、代码里只有草稿接口没有发布接口、图片只在临时目录处理、每次推稿自动回读核对。

工具的价值不是炫技，而是把你从重复劳动里赎出来。
